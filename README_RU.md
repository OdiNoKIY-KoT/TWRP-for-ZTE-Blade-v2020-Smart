TWRP для ZTE Blade V2020 Smart

Другие названия устройства: ZTE 8010 / P963F05

---

О проекте

В этом репозитории находится экспериментальная тестовая сборка TWRP (Team Win Recovery Project) для ZTE Blade V2020 Smart

«[!ПРЕДУПРЕЖДЕНИЕ]
Это экспериментальная тестовая версия, разработанная при помощи ИИ. Возможны ошибки, неполная функциональность и проблемы совместимости.»

Источники и благодарности

Проект основан на существующих исходниках для данного устройства:

- Device Tree: Получен с помощью "twrpdtgen", на основе адаптированной под устройство версии от "XvSvM" (https://github.com/XvSvM).
- Дополнительные изменения: Корректировки разметки разделов и работы с шифрованием, выполненные при помощи ИИ.

Отказ от ответственности

Данная сборка предоставляется исключительно для тестирования и разработки. Использование осуществляется на свой страх и риск. Стабильность работы и сохранность данных не гарантируются.
